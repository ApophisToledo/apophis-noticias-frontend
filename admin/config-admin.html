Configurar Admin

Guía rápida para activar login real.

Generar contraseña segura

Desde la carpeta backend ejecutá:

node scripts/generate-admin-hash.js TU_PASSWORD_SEGURA

Variables necesarias

ADMIN_EMAIL=admin@apophis.com
ADMIN_PASSWORD_HASH=hash_generado
JWT_SECRET=clave_larga_segura

Después reiniciá el backend y entrá desde /admin/login.html.
